Private Image Splitter

A lightweight, privacy-first web application that allows you to easily split images into predefined horizontal, vertical, or grid layouts. Built with simplicity and security in mind, this tool processes everything locally in your browser—meaning your images never leave your device.

✨ Features

100% Private & Offline: Utilizes the HTML5 Canvas API for entirely client-side processing. No servers, no uploads, zero tracking.

Multiple Split Options: Choose from 7 different layout configurations, including 2/3/4 rows, 2/3/4 columns, or a 2x2 grid.

Modern, Zen UI: A clean, dual-pane card layout featuring a tactile "premium button" aesthetic, with full support for both Light and Dark modes.

High Quality: Maintains your original image quality and supports standard web formats (JPG, PNG, WEBP).

Zero Dependencies: The entire application is contained within a single index.html file, styled with Tailwind CSS via CDN.

🚀 Getting Started

Simply clone the repository or download the index.html file and open it in any modern web browser. No installation, build steps, or local servers are required.
